# Sky Tab — تب جدید کروم

تب جدید مینیمال و شیشه‌ای با **آسمان زنده**: پس‌زمینه از آب‌وهوای واقعی و ساعت واقعی طلوع/غروب شهر شما ساخته می‌شود.

## امکانات

- **آسمان زنده** — رنگ آسمان بر اساس ارتفاع واقعی خورشید (طلوع و غروب همان شهر)، خورشید و ماه (با فاز واقعی ماه)، ستاره‌ها، ابر، باران، نم‌نم، برف، رعد و برق و مه.
- **آب‌وهوای واضح** — چیپ بالای صفحه (آیکون + دما + وضعیت به فارسی + شهر)؛ با کلیک، پنل جزئیات باز می‌شود: احساس‌شده، رطوبت، باد، احتمال بارش، طلوع/غروب، ساعت‌های آینده و ۵ روز آینده.
- **دفترچه یادداشت** — کنار صفحه؛ هر چیزی که بنویسی و Enter بزنی مثل یک پیام ثبت می‌شود. با ✅ می‌شود علامت «انجام دادم» زد، با ☺ ایموجی‌های دیگر، فیلتر «فقط کارهای باز» و پاک‌کردن انجام‌شده‌ها.
- **نشانک‌های دسته‌بندی‌شده** — افزودن با دسته‌بندی، جمع/باز کردن دسته‌ها، حذف نشانک یا دسته (با دکمهٔ «برگردان»).
- **تنظیمات** — جستجوی شهر یا موقعیت من، °C/°F، اندازهٔ متن، خاموش‌کردن افکت‌ها، کنتراست بالا، و پیش‌نمایش حالت‌های آسمان.
- **دسترسی‌پذیری** — دیالوگ‌های بومی با تله‌ی فوکوس، برچسب‌های ARIA، حلقهٔ فوکوس واضح، احترام به «کاهش حرکت»، کنتراست متن بالای ۴٫۵ در همهٔ حالت‌های آسمان.

میانبرها: `/` جستجو · `N` یادداشت جدید · `Esc` بستن.

## نصب

1. در کروم به `chrome://extensions` بروید و **Developer mode** را روشن کنید.
2. **Load unpacked** را بزنید و همین پوشه را انتخاب کنید.
3. یک تب جدید باز کنید.

داده‌ها (نشانک‌ها، یادداشت‌ها، تنظیمات) فقط در `chrome.storage.local` همین مرورگر ذخیره می‌شوند. آب‌وهوا از [Open-Meteo](https://open-meteo.com) (بدون کلید API) گرفته می‌شود.

## ساختار

```
manifest.json
index.html
css/style.css
js/main.js        راه‌اندازی، ساعت، پنل آب‌وهوا، تنظیمات
js/sky.js         آسمان: رنگ، خورشید/ماه، ابر، ستاره، باران/برف/رعد
js/weather.js     Open-Meteo، متن فارسی، آیکون‌ها
js/notes.js       دفترچه یادداشت
js/bookmarks.js   نشانک‌های دسته‌بندی‌شده
js/store.js       ذخیره‌سازی (و انتقال داده‌های نسخهٔ قبل)
js/ui.js          toast / دیالوگ
fonts/            وزیرمتن (متغیر)
```
